# DEADWEIGHT v1.0 — technical contract

Work is organised as task cards in `docs/TASKS.md`. Executors read `docs/EXECUTOR_BRIEF.md`,
their card, and the sections of this contract that the card cites. The contract wins over
guesses. If you must deviate, keep the documented API working and report the deviation.

## 0. Rules for agents

1. **Edit only the files your task card lists.** Section 3 shows the long-term module areas
   for orientation. Need something elsewhere? Report it as a blocker. Never edit
   `project.godot`, `main.tscn` or `docs/` (except TASKS status + PROGRESS) unless your card
   says so.
2. **Godot binary:** `.tools/godot/Godot_v4.7.2-stable_win64_console.exe` (Godot 4.7.2 stable,
   GDScript, Jolt physics). Run from the project root.
3. **Headless tests:**
   `.tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 90 --path . --script res://tests/<name>.gd`
   A test is a `extends SceneTree` script that prints `PASS ...`/`FAIL ...` lines and quits
   with exit code 0 (all pass) or 1. Parse check without running:
   `... --headless --path . --check-only --script res://path/to/file.gd`
4. **Rendered captures (to look at your work):** run windowed but off-screen so nothing
   pops up on the user's monitor:
   `... --path . --position 20000,20000 --resolution 1280x720 --script res://tests/<preview>.gd`
   Save PNGs under `.tools/captures/<your-area>/` (ignored by git and exports) and **open
   them with your image-reading tool and critique them**. Desktop uses Forward+; add
   `--rendering-method gl_compatibility` to preview the mobile renderer.
5. **Never touch the player's real save.** Tests/previews use their own profile path
   (e.g. `user://test_meta.cfg`) or the `--profile=` argument.
6. Do **not** run `--editor`, `--import` or exports unless your card says so. If a failure is
   in a file outside your card, report it instead of fixing it. The quality gate is
   `tests/run_all.ps1`.
7. Do not use `class_name`. Load scripts with `preload("res://...")` / `load()` and `.new()`.
   If a script owned by someone else may not exist yet, guard with `ResourceLoader.exists()`.
8. Typed GDScript (tabs for indentation). Annotate types when assigning from Dictionary,
   Variant or `get()` results. Keep functions short; comment intent, not mechanics.
9. All art and sound are generated by code (no downloaded assets, fonts or plugins).
10. Finish with a report: files written, public API deviations, test commands + results,
    known issues, integrator requests.

## 1. Conventions

- Units: metres, kilograms, seconds, newtons. Physics 90 Hz, gravity 12 m/s², Jolt.
- Desktop renderer Forward+, mobile renderer Compatibility (GLES3). Everything must work
  and look acceptable in both. No Decal, SDFGI, or compute-only features as essentials;
  Forward+-only extras (SSAO, volumetric fog) are optional quality bonuses.
- UI canvas: 1280×720 base, `canvas_items` stretch, `expand` aspect. Must fit 16:9, 16:10
  (Steam Deck 1280×800), 4:3 and 20:9 phones; respect mobile safe areas.
- `pointing/emulate_mouse_from_touch=true`: touch also produces mouse events for index 0.
  Gameplay code ignores mouse events while `touch_enabled`.
- Text style: terse uppercase labels for HUD/UI chrome; sentence case for longer copy.
- Persistence: `user://profile.cfg` (ConfigFile) owned by `profile.gd`.

## 2. Collision layers and groups

| Bit value | Use | Mask of the body |
| --- | --- | --- |
| 1 | WORLD static geometry, anchors | 0 |
| 2 | PLAYER (RigidBody3D capsule) | 1 |
| 4 | WEIGHT (cast weights) | 1 \| 8 |
| 8 | ENEMY (CharacterBody3D) | 1 |

Pickups, extraction, hazards, updrafts and hint zones are proximity/AABB checks done by
the level each physics frame — no Area3D needed.

Groups: `player`, `enemies` (living enemies), `anchor` (StaticBody3D anchor plates),
`cast_weight` (attached + loose weights), `sun` (level DirectionalLight3D),
`world_env` (level WorldEnvironment), `game_audio` (audio.gd node), `game_music`
(music.gd node).

### 4.7 `scripts/main.gd` — scene root `Node3D` (META)

Owns the state machine (`boot`, `title`, `menu`, `loading`, `playing`, `paused`, `result`),
creates `Player`, `Tether`, `HUD`, `UIRoot`, `Audio`, `Music`, `Platform`, and the current
level. Routes input (mouse/keyboard/gamepad here; touch via HUD signals), tracks run stats,
checkpoints, fall-out, achievements, rewards and saving. Applies upgrade stats on every run
start (`player.configure`, `tether.configure`) and settings whenever they change.

Command-line user arguments (after `--`), used by tests, previews and store captures:

| Argument | Effect |
| --- | --- |
| `--profile=<path>` | use that profile file instead of `user://profile.cfg` |
| `--level=<id>` | skip the title, start that level (`range` = practice range) |
| `--screen=<name>` | open a UI screen: title, levels, workshop, settings, credits, records, pause, result, loading |
| `--cam=x,y,z,yaw_deg,pitch_deg` | after start, freeze the player there with that view |
| `--hide-ui` | hide HUD and menus (clean shots) |
| `--unlock-all` | treat every level as unlocked (does not save) |
| `--touch` | force touch controls on desktop |
| `--capture` / `--capture-path=<png>` / `--capture-delay=<frames>` | save one frame (default 90 frames in) and quit |
| `--windowed` | never change window mode or size |

Any of `--capture`, `--windowed`, a `--script` run or the editor disables window changes.

### 5.3 Difficulty damage scale
`[0.5, 1.0, 1.5][difficulty]` → `level.damage_scale` (enemies and hazards).

### 5.4 Level record and stats
Level record: `{"completed": bool, "best_time": float (-1 = none), "medal": int 0..3,
"bonus_found": Array (bonus indices ever collected), "attempts": int, "extractions": int}`.
Unlock: `tutorial` and `l01` always; any other campaign level when the previous campaign
level is completed. `range` always.
Stats: `{"play_time": float, "casts": int, "kills": int, "smash_kills": int, "deaths": int,
"extractions": int, "salvage_earned": int, "max_speed": float, "max_airtime": float}`.

### 5.5 Run summary (`profile.record_run(run)`)
Input: `{"level_id", "won": bool, "time": float, "cases": int, "bonus_indices": Array,
"total_bonus": int, "damage_taken": float, "shots": int, "kills": int, "smash_kills": int,
"enemies_present": bool, "max_speed": float, "max_airtime": float, "casts": int}`.
Output: `{"salvage": int, "breakdown": Array of [label: String, amount: int],
"medal": int, "previous_medal": int, "best_time": float, "new_best": bool,
"first_clear": bool, "next_unlocked": String}` (failed runs: salvage 0, medal 0).

### 5.6 Level `INFO` constant (declared by every level script)
`{"title": "SLUICE GATE", "zone": "floodworks", "number": 1, "blurb": "One line.",
"par_silver": 150.0, "par_gold": 95.0, "cases": 3, "bonus": 2, "enemies": true,
"practice": false}`. `range` uses `"practice": true` and `"number": -1`; tutorial `0`.

### 5.7 Input actions
`move_left move_right move_forward move_back look_left look_right look_up look_down
cast lock reel cut weapon reload jump pause` plus Godot's built-in `ui_*` actions (ensure
gamepad left stick + D-pad + A/B are mapped for UI). Bindings per DESIGN controls table.
Reel analog strength = `Input.get_action_strength("reel")`.

### 5.8 Objectives (`level.get_objectives()`)
Array of `{"position": Vector3, "kind": "case" | "bonus" | "extract", "label": String,
"active": bool}` — uncollected cases and bonuses; extraction always present with
`active = (collected_loot >= total_loot)`.

### 5.9 HUD `update_state` keys (all optional)
`health, max_health, speed, tension, max_tension, line_length, max_line, reel_state
(String), charge (0..1), anchored (bool), weapon ("ROD"|"SIDEARM"), ammo, reserve,
reloading (bool), loot, total_loot, bonus, total_bonus, extraction (0..1),
extraction_inside (bool), extraction_ready (bool), time, par_silver, par_gold, hint
(String, tokens already expanded), hitmarker (0..1), danger (0..1), practice (bool),
level_title, airborne (bool), alert (bool), device ("kbm"|"gamepad"|"touch")`.

### 5.10 Result (`ui.show_result`)
`{"won": bool, "level_id", "title", "time", "cases", "total_cases", "bonus",
"total_bonus", "salvage", "breakdown", "medal", "previous_medal", "best_time",
"new_best", "par_silver", "par_gold", "bank", "next_level" ("" if none),
"achievements": Array of titles unlocked this run, "cause" (death cause: "hound",
"sentry", "drone", "fall", "hazard", ""), "stats": {"max_speed", "max_airtime",
"casts", "kills", "damage_taken"}}`.

### 5.11 Audio event ids
Rod `cast lock release cut anchor recover spool_limit severed weight_impact smash
reel_stall`. Player `jump land land_hard footstep hurt death`. Weapon `shot hit kill reload
empty switch`. Objective `loot bonus extract_ready extract_tick extract_break win lose medal
checkpoint`. Enemy (positional) `hound_alert hound_bite sentry_charge sentry_shot
drone_charge drone_shot enemy_death`. World `hazard_zap updraft splash`. UI `ui_move
ui_accept ui_back ui_buy ui_denied ui_unlock ui_toggle`. Loops are internal (`motion()`):
wind, reel, tension creak. `get_stream("drone_hum")` returns a loop for drone players.

## 7. Performance budgets (mobile Compatibility renderer is the constraint)

- ≤ 160 draw calls in a typical view, ≤ 250k triangles per level, ≤ 6 OmniLights per level.
- Static geometry merged per material; Label3D count ≤ 60 per level; one shadowed sun.
- No per-frame allocations in hot loops beyond small arrays; rope mesh rebuilt per frame
  is fine (≤ 64 segments).
- Target 60 FPS on mid-range 2021 Android phones at render scale 0.85, quality Medium.

## 8. Visual style

The Department of Unfinished Gravity (owner-directed visual revision, 2026-11-03):
absurdist public works architecture with ceramic surfaces, oversized domestic objects,
unusable doors, repeated arches and a painted afternoon sky. See `docs/DREAMSCAPE.md`.
Palette anchors (Floodworks): chalk `#d6c9b0`, porcelain `#e2dac6`, plum `#473c52`,
dusty rose `#bd8380`, brass `#c5a264`, celadon `#819c96`.
UI: ink `#211c2d`, paper `#f2e6cf`, muted `#b6b2ba`, amber `#e8bd80`, cyan `#a3d5ca`.
Existing red danger, cyan route/objective, and amber action/salvage cues remain semantic.
Generated textures are allowed under `assets/dreamscape/`, with exact prompts and provenance.
Use world-space projection for architecture and an antialiased checker shader for floors.
Dream dressing joins existing static batches and adds no collision, lights or nav obstacles.
Compatibility uses at most two sun-shadow cascades; main enemy volumes cast shadows,
while small fittings do not. Fixed sentry fittings are merged into one mesh.
